## 1. ページ構成とナビゲーション

グローバルナビは**5項目**。11項目のナビはスマホで機能しない。

| ナビ | ファイル | 内包する内容 |
|---|---|---|
| 大会 | `tournaments.html` | 大会一覧（年度・状態別）。結果 `results.html`・クラブ対抗戦 `club-league.html` への入口 |
| 協会登録 | `membership.html` | 個人・クラブの年度登録 |
| 教室・イベント | `school.html` | 水曜テニス教室・テニスの日 |
| 協会について | `about.html` | 挨拶・活動内容・役員名簿・協会規約 |
| お問い合わせ | `contact.html` | メール・LINE公式アカウント |

- 大会詳細は `tournament.html?id=<slug>`（1大会=1ページ。要項・ドロー・結果・ライブスコアを集約）

- ヘッダー右端に `[ エントリー ]` ボタン（`--ball`）。**受付中の大会があるときだけ表示**
- LINE公式はフッターとお問い合わせページに常設。ナビからは外す

## 2. トップページ

### 2-1. 緊急告知バー（条件表示）
`data/settings.json` の `siteNotice` に文字が入っているときだけ最上部に表示。
> 例）本日8月9日のサマーミックス大会は、雨天のため中止します。

### 2-2. ヒーロー
- 背景：**全幅の写真または動画**（コート俯瞰／プレー中／ナイターの会場）。仕様は design.md §9-1
  - 素材は後から追加する。用意できるまではコート図SVGを仮置きし、**差し替えは1箇所**で済ませる
  - 動画を使う場合も音声なし・8秒以内。モバイルと `prefers-reduced-motion` では静止画に落とす
- 背景の上に半透明のオーバーレイを敷き、白文字のコントラストを素材によらず担保する
- ブラケット線が受付中大会カードへ接続（design.md §5）
- 受付中の大会があるとき、カードを重ねる：

```
● 受付中
第49回ダンロップテニストーナメント鳥取県大会
8月12日(水) 締切 ／ 布勢庭球場
[ エントリーする → ]
```

- 受付中の大会が無いとき：

```
次回大会の受付は準備中です
令和8年度の大会日程はこちらから確認できます
[ 大会日程を見る → ]
```

### 2-3. 大会・エントリー（最大4件）
開催日が近い順。日付ブロック（Barlow Condensed）＋大会名＋会場＋状態バッジ。
末尾に `[ すべての大会を見る → ]`

### 2-4. お知らせ（最大5件）
新着順。カテゴリチップ＋日付＋タイトル。
カテゴリ：`大会情報` / `結果` / `事務連絡` / `教室` / `重要`
末尾に `[ お知らせ一覧 → ]`

### 2-5. 協会登録（濃色帯）

## 4. 大会詳細 `tournament.html?id=<slug>`

**1つの大会に関する情報を1ページに集約する。** 要項・ドロー・結果がページを跨がない。

```
[ パンくず ] 大会 > 令和8年度 > 第49回ダンロップテニストーナメント鳥取県大会

● 受付中
第49回ダンロップテニストーナメント鳥取県大会

開催日   2026年8月29日(土)・30日(日)
会場     布勢総合運動公園テニスコート
種目     男子シングルス／女子シングルス／男子ダブルス／女子ダブルス
参加費   一般 4,000円 ／ 学生 2,500円
締切     2026年8月12日(水) 23:59

[ エントリーする → ]        ← 受付中のときのみ活性
[ 要項PDFをダウンロード ]    ← 補助。本文は下に全文掲載

── ページ内タブ ─────────────
[ 要項 ]  [ ドロー ]  [ 結果 ]
（未公開のタブは表示しない。「準備中」タブは作らない）

■ 要項  … HTML本文（参加資格・申込方法・支払方法・雨天時の扱い・問い合わせ先）
■ ドロー … 表またはSVG。画像貼付は避ける。PDFは補助として併置
■ 結果  … 種目／優勝／準優勝 の表で持つ。スクリーンショットを貼らない
```

**エントリーボタンの状態別文言**

| 状態 | 表示 |
|---|---|
| 受付前 | `8月1日(土) 受付開始`（非活性） |
| 受付中 | `エントリーする →` |
| 締切間近 | `エントリーする → 残り2日` |
| 締切後 | `受付は終了しました`（非活性） |
| 定員到達 | `定員に達しました`（非活性） |

```
協会登録

鳥取市テニス協会の主催大会に出場するには、年度ごとの登録が必要です。
登録は鳥取県テニス協会への登録を兼ねます。

■ 令和8年度の登録について
  登録期間   2026年4月1日〜（随時受付）
  登録料     一般 ◯,◯◯◯円 ／ 学生 ◯,◯◯◯円 ／ ジュニア ◯,◯◯◯円
  支払方法   （協会の指定方法を記載）

[ 個人で登録する → ]
[ クラブで登録する → ]

■ 登録の流れ
  1. フォームに入力する
  2. 受付メールが届く（支払方法の案内が記載されています）
  3. 登録料を支払う
  4. 登録完了メールが届く

■ よくある質問
  Q. 昨年度に登録しています。今年も必要ですか？
  A. 必要です。登録は年度ごとの更新制です。

  Q. クラブに所属していませんが登録できますか？
  A. できます。個人登録をご利用ください。

  Q. 登録しないと大会に出られませんか？
  A. 大会によります。各大会の要項をご確認ください。

■ 従来の用紙での登録
  [ 登録用紙（PDF） ]
  ※WEB登録の運用開始後も、当面は用紙での登録を受け付けます。
```

> **移行期の配慮：** WEB登録に切り替えても紙の用紙を即座に廃止しない。並行運用の期間を明示する。
