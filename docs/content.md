# 鳥取市テニス協会 公式サイト コンテンツ指示書（content.md）

現行サイト（https://www.tottori-tenis.net/ ・ジンドゥー運用）の内容を再構成する。
今後「協会登録」「大会エントリー」をWEB上で行うことを想定した導線を全ページに用意する。

## サイト全体

- サイト名: 鳥取市テニス協会（英字: TOTTORI CITY TENNIS ASSOCIATION）
- 対象: 協会員・加盟クラブ、大会参加者、テニス教室参加希望者、市民
- 常設CTA: 「大会エントリー」「協会登録」

## ページ構成

| ページ | ファイル | 目的 |
|---|---|---|
| トップ | index.html | 新着・直近大会・主要導線への入口 |
| 新着情報 | news.html | お知らせ一覧（カテゴリ絞り込み） |
| 大会案内 | tournaments.html | 年間スケジュール・要項・エントリー |
| 大会結果 | results.html | 大会結果（年度別） |
| 協会登録 | membership.html | 個人・クラブ登録の案内とWEB登録導線 |
| テニス教室 | school.html | 水曜テニス教室ほか教室案内 |
| 協会について | about.html | 挨拶・活動内容・沿革・加盟クラブ |
| お問い合わせ | contact.html | 連絡手段・LINE公式アカウント |

## トップページ

1. **ヒーロー**
   - キャッチ: 「鳥取のテニスを、もっと身近に。」
   - サブ: 大会運営・テニス教室・協会登録の案内。初心者からベテランまで。
   - CTA: 「大会エントリー」「協会登録はこちら」
2. **お知らせ（新着3〜6件）** → news.html へ
3. **直近の大会（エントリー受付中を強調）** → tournaments.html へ
4. **協会の活動（3カード）**: 大会運営 / テニス教室 / 協会登録
5. **LINE公式アカウント誘導バナー**
6. **フッター**

## 掲載コンテンツ（現行サイトより再構成）

### 大会（年間・例）
- 鳥取市テニス協会 会長杯テニス大会（春の部・秋の部）ダブルス
- 鳥取市クラブ対抗戦（前期・後期）
- 佐々木杯テニス大会
- 鳥取県東部テニス選手権大会
- 市民スポーツ祭 テニス競技

### テニス教室
- 水曜テニス教室（毎週水曜 19:00–21:00 / 鳥取市営コート / 初心者歓迎）

### 協会登録
- 年度ごとの個人登録・クラブ登録（現行: R7登録の案内を掲載）
- 今後: WEBフォームからの登録＋オンライン決済を予定 → 準備中の案内を掲載

### お知らせカテゴリ
- お知らせ / 大会案内 / 大会結果 / テニス教室

## 運用要件（重要）

- お知らせ・大会・結果は **data/*.json** で管理し、HTMLを触らず更新できること
- スマートフォンのブラウザから管理画面（/admin）で追加・編集・写真アップロードができること
- 画像は原本のままコミットし、表示側で品質を保つ（端末依存の再圧縮をしない）
- 大会データは「エントリー受付中/受付前/終了」のステータスと申込URL欄を持ち、
  将来のWEBエントリーフォーム（Googleフォーム等→専用システム）に差し替え可能にする
