# 鳥取市テニス協会 公式サイト デザインガイドライン（design.md）

参考サイト（ACES Inc. / ds-k.site）の「余白を活かしたクリーンなコーポレートデザイン」を基調に、
スポーツ団体らしい躍動感と信頼感を両立させる。

## 1. コンセプト

- **キーワード**: 誠実 / 開かれた協会 / 躍動 / クリーン
- 行政・学校関係者や初めての参加者が見ても信頼できる「公式感」
- テニスの爽やかさを想起させる配色と、大きな余白・大きめのタイポグラフィ
- 装飾よりも情報の整理を優先。1画面1メッセージ

## 2. カラーパレット

| 役割 | 色 | 変数名 |
|---|---|---|
| ベース | `#FFFFFF` / `#F5F7F6`（薄グレー緑） | `--c-bg` / `--c-bg-alt` |
| メインテキスト | `#1A2E35`（濃紺グリーン） | `--c-text` |
| サブテキスト | `#5A6B70` | `--c-text-sub` |
| プライマリ（協会カラー） | `#0E5E4A`（コートグリーン／深緑） | `--c-primary` |
| プライマリ濃 | `#0A4436` | `--c-primary-dark` |
| アクセント | `#D8F34E`（テニスボールイエロー） | `--c-accent` |
| ライン・罫線 | `#E3E8E6` | `--c-line` |
| 注意・締切 | `#C0392B` | `--c-alert` |

- ベタ塗りの多用は避け、白ベース＋プライマリの面をセクション単位で切り替える
- アクセント（ボールイエロー）はCTAボタン・マーカー・装飾点にのみ少量使用

## 3. タイポグラフィ

- 日本語: **"Zen Kaku Gothic New"**（Google Fonts）、fallback: "Hiragino Kaku Gothic ProN", "Noto Sans JP", sans-serif
- 英字見出し（装飾）: **"Outfit"**（Google Fonts）
- 本文: 16px / 行間 1.9 / 字間 0.02em
- 見出しは日本語＋小さな英字ラベルの2段構成（例: 「新着情報 / NEWS」）

| 要素 | サイズ(PC) | サイズ(SP) | ウェイト |
|---|---|---|---|
| H1（ヒーローコピー） | 44–56px | 30–36px | 700 |
| H2（セクション見出し） | 32px | 24px | 700 |
| H3（カード見出し） | 20px | 18px | 600 |
| 本文 | 16px | 15px | 400 |
| 英字ラベル | 13px 字間0.2em | 12px | 600 |

## 4. 余白・レイアウト

- コンテンツ最大幅: **1120px**（テキスト主体ページは 760px）
- セクション上下余白: PC **120px** / SP **72px**
- カード・要素間: 24–40px。詰めない。迷ったら広めに
- グリッド: ニュース・大会カードは PC 3カラム / タブレット 2 / SP 1
- 角丸: カード 16px / ボタン 999px（ピル型）/ 画像 12px

## 5. コンポーネント

- **ヘッダー**: 白背景・下線1px。ロゴ左、ナビ右。SPはフルスクリーンのドロワーメニュー。
  「大会エントリー」だけピル型のプライマリボタンで常設
- **ヒーロー**: 全幅。左にキャッチコピー＋CTA2つ、背景はコートを想起させる抽象ライン＋写真。
  スクロールで薄くフェードアップ
- **ニュースカード**: 日付（英字）＋カテゴリバッジ＋タイトル。ホバーで浮き上がり(4px)＋影
- **カテゴリバッジ**: 塗り分け（お知らせ=グリーン枠 / 大会=グリーン塗り / 結果=紺 / 教室=イエロー）
- **CTAボタン**: プライマリ塗り（白文字）と、白地グリーン枠の2種。矢印アイコン付き
- **フッター**: 濃紺グリーン地・白文字。サイトマップ＋LINE・お問い合わせ導線

## 6. アニメーション

- スクロール連動のフェードアップ（`opacity 0→1` / `translateY 24px→0` / 0.7s ease-out）を基本とし、多用しない
- ヒーローの装飾ライン（SVG）はゆっくり描画
- `prefers-reduced-motion` 時はすべて無効化

## 7. 画像ルール

- 掲載写真は **横長 3:2 または 16:9** に統一し、`object-fit: cover` でトリミング表示
- 端末やアップロード方法によらず品質が揃うよう、**原本をそのままGitにコミット**し、
  表示側でCSSによりリサイズする（Jimdoのような自動再圧縮を行わない）
- 写真がない場合はコートグリーンの抽象グラフィック（SVG）で代替し、空白を作らない

## 8. アクセシビリティ

- コントラスト比 4.5:1 以上（アクセントイエローの上は必ず濃紺テキスト）
- フォーカスリング可視化、ナビはキーボード操作可能に
- 日付・締切は色だけでなくテキストでも明示
